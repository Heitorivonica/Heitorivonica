# Olá 👋, eu sou o Heitor

🚀 **Desenvolvedor Fullstack | Foco em Front-end com React e JavaScript**  
🎓 Formado em Análise e Desenvolvimento de Sistemas (ENIAC) · Cursando Engenharia de Software  
🇧🇷 Brasil

Sou desenvolvedor fullstack com foco em **front-end**. Construo interfaces com **React** e **JavaScript**, pensando em layouts responsivos que funcionam bem no computador, no Android e no iPhone. No back-end, desenvolvo **APIs REST** e integro bancos de dados **SQL** e **MongoDB**.

Vim do **suporte técnico e infraestrutura**, onde aprendi a resolver problemas e a enxergar o sistema pelo lado de quem usa. Hoje levo essa visão para cada interface que construo: algo simples de usar e que resolve o problema de verdade.
